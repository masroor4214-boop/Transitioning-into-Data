## Data Career Paths Analysis

This Power BI dashboard analyses survey data from 630 data professionals to identify trends in career transitions, salary distribution, programming language preferences, job-seeking priorities, and workforce demographics.

The dashboard was developed to answer key business questions, including:

- How difficult is it to break into the data industry?
- How many professionals transitioned into data from another career?
- Which programming languages are most commonly used?
- What salary ranges are most common amongst respondents?
- What factors are most important when searching for a new role?
- Where are data professionals located globally?

### Key Findings

- 59% of respondents transitioned into data from another profession.
- 31.75% reported that entering the data field was difficult or very difficult.
- Python was the most widely used programming language.
- Better salary was the leading factor influencing job changes, followed by remote working opportunities and work-life balance.
- Most respondents fell within the $0–40k and $41k–65k salary bands.
